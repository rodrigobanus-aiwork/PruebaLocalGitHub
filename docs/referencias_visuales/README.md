# Referencias visuales aprobadas

Esta carpeta recibirá las **capturas reales que el usuario apruebe** (no generadas ni reconstruidas).

Para cada captura registrar al lado, en un archivo Markdown del mismo nombre: versión de código, dimensión de ventana, zoom, categoría, red, período, filtros, cuentas seleccionadas y datos usados.

**Pendiente:** incorporar imágenes de referencia originales del Dashboard por el usuario; este paquete no supone su aprobación ni incluye capturas inventadas.
